Future Institute - HTML/CSS/JavaScript Assignment
Made for student practice.

Files:
- index.html
- about.html
- courses.html
- students.html
- registration.html
- contact.html
- profile.html
- style.css
- script.js

How it works:
1. Open index.html.
2. Register a student from Registration.
3. After submit, a small success animation appears.
4. The browser opens profile.html with the student's details.
5. The registered student is also added to students.html.
6. Data is stored in browser localStorage, so no database is required.

Note:
The institute/student images use online image URLs, so internet is needed for those images.
